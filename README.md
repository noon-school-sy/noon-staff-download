# نون - الطاقم 📱

تطبيق أندرويد لطاقم المدرسة على منصة **نون للمدارس**: المدير والمعلم ومشرف/ة الباص.

## التنزيل
**[⬇️ تنزيل آخر نسخة (noon-staff.apk)](https://github.com/noon-school-sy/noon-staff-download/raw/main/noon-staff.apk)**

1. افتح الرابط من موبايل أندرويد ونزّل الملف.
2. افتح الملف واسمح بـ «التثبيت من هذا المصدر» إذا طلب ذلك، ثم «تثبيت».
3. ادخل بكود المدرسة واسم المستخدم وكلمة السر التي أعطتك إياها الإدارة.

النسخة الحالية: **1.0** — التحديثات تظهر داخل التطبيق تلقائياً.
